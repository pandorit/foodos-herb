# מדריך הקניות הכשר של פודוס - iHerb

אתר מקצועי להמלצות מוצרים כשרים מאיהרב עבור קהילת פודוס (56,000+ חברים).

## קישורים מהירים

- **אתר ציבורי:** פתחו את `index.html`
- **פאנל ניהול:** פתחו את `admin.html`
- **סיסמת ניהול:** `fodos2026`

## איך להשתמש באתר

### לצפייה באתר
1. פתחו את `index.html` בדפדפן
2. האתר מציג רק מוצרים מאושרים (approved: true)
3. אפשר לחפש, לסנן לפי קטגוריה/כשרות/מותג

### פאנל ניהול
1. פתחו את `admin.html`
2. הזינו סיסמה: `fodos2026`
3. תוכלו:
   - לאשר/לדחות מוצרים
   - להוסיף מוצרים חדשים
   - לחפש ולסנן מוצרים

## הוספת מוצרים

### דרך פאנל הניהול (מומלץ)
1. היכנסו לפאנל הניהול
2. לחצו "הוסף מוצר"
3. מלאו את הפרטים
4. המוצר יתווסף כ"ממתין לאישור"
5. לחצו על ✅ לאישור

### דרך קובץ data.js (מתקדם)
הוסיפו אובייקט למערך `products`:

```javascript
{
    id: 24,  // מספר ייחודי
    name: 'Product Name',
    nameHe: 'שם המוצר בעברית',
    brand: 'Brand Name',
    category: 'cacao',  // מזהה קטגוריה
    kosher: 'OU',
    kosherClass: 'ou',  // ou / ok / kofk / stk
    price: '$9.99',
    priceNum: 9.99,
    rating: 4.5,
    reviews: 1000,
    link: 'https://www.iherb.com/...',
    approved: true,  // true = מוצג, false = מוסתר
    description: 'תיאור קצר',
    whySpecial: 'למה המוצר מיוחד',
    uses: ['שימוש 1', 'שימוש 2', 'שימוש 3'],
    chefTip: 'טיפ מקצועי',
    whyIherb: 'למה לקנות מאיהרב'
}
```

### מזהי קטגוריות
- `cacao` - קקאו ושוקולד
- `flours` - קמחים לאפייה
- `baking` - תוספי אפייה
- `spices` - תבלינים ועשבי תיבול
- `sweeteners` - ממתיקים טבעיים
- `asian` - מטבח אסייתי
- `salts` - מלחים וגימור
- `superfoods` - סופרפודס
- `nutbutters` - חמאות אגוזים
- `gourmet` - גורמה ומיוחדים
